# SELL 出場策略 + Entry Filter 比較研究

研究問題：現行 SELL 邏輯（停損% / 停利% / 標準信號 / S8 trend_break = 從 20 日高點下跌 3×ATR）在多頭市場很少被觸發，擔心進入空頭/急殺段時「等跌 3×ATR 才賣」會在波段高點賣出（從高點掉 8-15%）。

本研究：在歷史資料上比較 8+ 個 SELL 策略，測量「從持倉最高點到實際 SELL 的回落」、勝率、MDD、假訊號率。**最終發現**：「持續盤整」段的漏血超過任何 SELL 策略差異，加上一個 entry filter（F3）就能讓所有策略提升 5-12pp。

> 純研究，未動 production code。所有檔案在 `scripts/backtest_exits/`。

## 🏆 結論先說

**冠軍組合：S1_trailing_atr (3×ATR) + F3 entry filter**

| 指標 | 現行 baseline (S0) | **S1 + F3** | Δ |
|---|---:|---:|---:|
| 全期報酬 | +45.6% | **+63.5%** | **+17.9pp** |
| MDD | -84.8% | **-59.6%** | **+25.2pp** |
| 持續盤整段 sum_pnl | -107K | -24K | +83K |
| 多頭段勝率 | 44.9% | 48.6% | +3.7pp |
| 急殺段（2024/8）avg_pnl | -3.4% | -6.4% ⚠ | -3.0pp |
| 急殺段（2025/4）avg_pnl | -2.0% | -3.9% ⚠ | -1.9pp |

**Trade-off**：S1 在 2024/8 急殺、2025/4 關稅段個別交易較痛（worst -15.6%），但**全期 MDD 反而最低**，因為 F3 阻止了在盤整期過度進場、急殺時部位較少。

## 三個關鍵發現

1. **「持續盤整」段是最大漏血點**，所有策略都負報酬（-104K~-143K），佔全期 PnL 影響超過所有 SELL 策略差異總和。
2. **盤整漏血主因是「進場錯」**，不是出場慢：buy_score 40-50 區段 75 筆吃掉 70% 漏血；強勢多頭+TAIEX neutral 是假突破集中地。
3. **F3 entry filter**（TAIEX neutral 時 buy_score 必須 ≥ 50）對全部 13 個策略都改善 +4~12pp 報酬、+10~25pp MDD。

## 設定

| 項目 | 值 |

| BUY 條件（共用） | `buy_score >= 40` 且 `buy_score > sell_score` 且未被 RegimeLayer veto |
| 共用 SELL 守則 | 停損%、停利%（依 sector）、標準綜合 SELL 信號（sell_score >= 40 且 > buy_score） |
| 期數 | 約 4.9 年（含 2022 全年空頭、2024/8 急殺、2025/4 關稅段） |
| 五策略差異 | 僅在「主動觸發出場」邏輯 |

### 五個 SELL 策略

| 代碼 | 名稱 | 觸發邏輯 |
|---|---|---|
| **S0** | baseline（現行） | S8（20 日高點 - 收盤 ≥ 3×ATR）or S9（連 3 黑 + 收盤 < MA20） |
| **S1** | trailing ATR | 持倉以來最高價 - 收盤 ≥ 3×ATR |
| **S2** | MA break | 收盤 < EMA21 |
| **S3** | adaptive trend_break | S8 的 ATR 倍數依 TAIEX regime 切換：bull 3.0、neutral 2.5、bear 1.5；S9 維持 |
| **S4** | regime combo | TAIEX bear → EMA21 break + 2×ATR trailing；bull/neutral → baseline（bear 時 S8 收緊到 2.0） |

`TAIEX regime`：bull = TAIEX > MA200 且 MA50 > MA200；bear = TAIEX < MA200 且 MA50 < MA200；其它 neutral。

## 主要發現

1. **「從高點到 SELL 跌幅」的恐懼略被高估**
   - baseline 全期平均 giveback = 4.26%、中位 3.38%，並非擔心的 8-15%。
   - 即使 2024/8 急殺也只到 5.67% / 16.11%（max）。
   - 但 max_giveback 偶有 ≥ 15-19% 的尾端事件，這些是真正痛的個案。

2. **單一策略無法同時贏**
   - **S1_trailing_atr** 多頭吃波段（+9.2% 年化、+53.6% 總報酬、MDD 最小 -70%），但空頭被洗（2022 giveback 5.88%、2024/8 急殺 giveback 10%、假訊號 47%）。
   - **S3_adaptive** 空頭穩（2022 giveback 3.26%、worst -11.97%），但多頭錯失波段（年化 7.4%，最差）。
   - **S2_ma_break** 急殺反應快，但長期太敏感（年化 8.1%，與 baseline 相當）。

3. **TAIEX MA200 判斷 bear 的盲點**
   - 2024/8 急殺時 TAIEX 還在 MA200 上方，S3 / S4 都沒切換成 bear 模式，giveback 與 baseline 相同。
   - 真正能在這段勝出的 S2 用的是「個股 EMA21 break」，與大盤狀態無關 → 個股級的觸發比大盤 regime 更敏銳。

4. **S4 目前實作沒有顯著優勢**
   - 邏輯接近「大盤 bear 才切換」，因 bear 觸發太慢而退化成 baseline。
   - 改進方向見下節。

### 為什麼 EMA21 + 2×ATR trailing 是好組合

- **EMA21 break**：型態確認，多頭時 EMA21 通常未破不觸發（避免被洗），急殺時 EMA21 與股價同步走低，跌破時機接近真實趨勢轉折
- **2×ATR trailing**：保命線，當股價大幅震盪導致 EMA21 跟不上時兜底
- **OR 並聯**：兩者誰先觸發都行 → 急殺時 EMA21 多半先觸發，緩跌時 2×ATR 先觸發
- 比 S1 (3×ATR only) 多了型態確認 → 避免在多頭被洗
- 比 S2 (EMA21 only) 多了 ATR 保險 → 在劇烈下殺確保不會等到 EMA21 才出

- 其它 → 2.0×ATR（標準）

S8 進一步把多頭區放寬到 2.5×ATR，但**沒幫助**（EMA21 break 已是主要驅動，ATR 變寬影響有限）。
